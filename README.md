# 정찬민 개인 홈페이지

기술개발연구프로젝트 2주차 과제 · 개인 홈페이지 첫 구현

한국외국어대학교 아랍어과 · Business AI 전공 정찬민의 개인 홈페이지입니다.
중동 무역·물류 데이터를 주제로 소개, 이력, 관심 분야, 준비 중인 프로젝트를 한 페이지에 담았습니다.
**한국어와 아랍어 두 가지 버전**을 제공하며, 상단 오른쪽 버튼으로 전환합니다.

## 실행 방법

설치나 서버 없이 브라우저로 바로 열 수 있습니다.

1. 이 폴더를 내려받아 압축을 풉니다.
2. `index.html`을 더블클릭하거나 브라우저 창으로 끌어 놓습니다.
3. `index.html`, `ar.html`, `style.css`, `script.js`는 반드시 같은 폴더에 두어야 합니다. 분리하면 언어 전환이나 색·배치가 적용되지 않을 수 있습니다.

외부 폰트·외부 이미지·프레임워크는 사용하지 않았습니다. `script.js`는 언어를 바꿀 때 현재 읽던 섹션을 유지하는 데만 사용합니다. 글꼴은 운영체제에 이미 있는 시스템 글꼴만 씁니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 한국어 페이지의 내용과 구조 |
| `ar.html` | 아랍어 페이지 (`dir="rtl"`, 오른쪽에서 왼쪽으로 읽음) |
| `style.css` | 두 페이지가 공유하는 색상·글자 크기·간격·배치 |
| `script.js` | 언어 전환 시 현재 섹션 해시를 유지하는 최소 JavaScript |
| `프로젝트_작성_템플릿.md` | 새 프로젝트를 사실 기반으로 추가하기 위한 작성·검증 양식 |
| `제출_기록.md` | 기획 메모와 자체 점검 기록 |
| `README_수업제공_원본.md` | 수업에서 제공한 시작 파일 안내 (참고용 보관) |

## 페이지 구성

- **첫 화면** — 한 문장 소개와 프로젝트 바로가기
- **소개** — 아랍어와 Business AI 두 전공을 무역·물류로 잇는 이유
- **이력** — 이름·출생·학교·전공, 자격증 3종(국제무역사 · SQLD · 운전면허 2종)
- **관심 분야** — 수요 예측 / 재고·발주 최적화 / 중동 시장과 무역
- **프로젝트** — 첫 중동 무역·물류 데이터 프로젝트의 설계 단계. 실제 데이터·방법·결과가 확인되면 같은 형식으로 아카이브를 확장
- **연락** — 이메일

## 한국어 · 아랍어 전환

상단 오른쪽 `한국어 / العربية` 버튼으로 두 페이지를 오갑니다. `script.js`가 현재 섹션의 해시를 이어 주므로
프로젝트 영역에서 언어를 바꾸면 다른 언어의 같은 프로젝트 영역으로 이동합니다. JavaScript가 꺼져도 두 페이지 전환 자체는 일반 링크로 동작합니다.

아랍어 페이지는 번역만 바꾼 것이 아니라 문서 자체를 아랍어 기준으로 맞췄습니다.

- `<html lang="ar" dir="rtl">` — 화면 전체가 오른쪽에서 왼쪽으로 뒤집힙니다. 메뉴 순서, 카드 배열,
  본문 정렬이 모두 자동으로 바뀝니다.
- 아랍어는 글자를 이어 쓰기 때문에 한국어에 쓴 좁은 자간(`letter-spacing: -0.03em`)을 `normal`로 되돌리고
  줄 간격을 넓혔습니다.
- 두 페이지가 `style.css` 한 개를 함께 씁니다. 색이나 간격을 고치면 양쪽에 동시에 적용됩니다.
- 이메일 주소만 `dir="ltr"`로 따로 지정해 왼쪽에서 오른쪽으로 표시됩니다.

## 첫 화면 배경 그림

사진 파일을 쓰지 않고 **SVG로 직접 그렸습니다.** 이유는 세 가지입니다.

1. 수업 규칙상 외부 이미지를 쓰지 않습니다.
2. 남의 사진을 쓰면 저작권 표기 문제가 따라옵니다.
3. SVG는 몇 KB라 배포해도 즉시 뜨고, 화면을 아무리 키워도 선이 깨지지 않습니다.

그림은 두 겹입니다.

- **세계지도** — 대륙 윤곽을 경도·위도 좌표로 근사해 그린 뒤, 그 안쪽에만 점 무늬를 채웠습니다
  (`clipPath` + `pattern`). 정밀 측량 자료가 아니라 배경 장식용 근사 윤곽입니다.
- **컨테이너 항로** — 실제로 오가는 경로를 따라 그렸습니다.
  **부산 → 싱가포르(말라카 해협) → 제벨알리 → 수에즈 → 지브롤터.**
  점선 위로 짧은 빛줄기가 흐르고, 부산과 제벨알리에는 신호가 퍼지는 링을 두었습니다.
  움직임은 `stroke-dashoffset` 애니메이션으로, **JavaScript 없이 CSS만** 씁니다.

지도는 실제 지리이므로 **아랍어 페이지에서도 좌우로 뒤집지 않습니다.** 글은 오른쪽에서 왼쪽으로 읽고
지도는 그대로 두는 것이 맞습니다. 항구 이름은 라틴 문자라 방향을 `ltr`로 고정했습니다.

제목이 지도 위에서도 또렷하게 읽히도록 글자 뒤에 배경색 스크림을 깔았습니다.
`prefers-reduced-motion`(화면 움직임 줄이기)을 켠 사용자에게는 모든 움직임이 멈춥니다.
좁은 화면에서는 지도 농도를 0.13에서 0.085로 낮춥니다.

## 접근성

수업 평가 항목이라 수치로 확인했습니다.

- **색 대비** — 본문·보조 글자·링크·버튼 등 16개 조합을 계산해 모두 WCAG AA 기준(4.5:1)을 넘겼습니다.
  가장 빠듯한 곳이 회색 섹션 위 보조 글자 4.66:1, 어두운 화면 카드 위 링크 4.70:1입니다.
- **키보드** — 맨 앞에 `본문 바로가기` 링크가 있고, Tab으로 이동할 때 파란 외곽선으로 현재 위치가 보입니다.
- **구조** — 제목 단계를 h1 → h2 → h3 순서로 건너뛰지 않게 배치했고, 각 영역에 `aria-labelledby`를 달았습니다.
- **동작 최소화 설정** — 브라우저에서 화면 움직임 줄이기를 켠 사용자에게는 부드러운 스크롤을 끕니다.
- 언어 버튼의 현재 언어에 `aria-current="page"`를 표시합니다.
- 배경 그림에는 `aria-hidden="true"`를 달아 화면 낭독기가 읽지 않습니다.

## 표시 원칙

- 프로젝트명·수치·결과는 확정하지 않은 상태에서 지어내지 않습니다. 현재 카드는 첫 프로젝트의 설계 단계와 검증 원칙만 표시합니다.
- 실제로 확인하지 않은 외부 링크는 넣지 않았습니다. 연락처는 본인 이메일 하나만 두었습니다.
- 화면 폭 390px에서도 가로 스크롤이 생기지 않도록 만들었습니다. 한국어·아랍어 두 페이지 모두 확인했습니다.

## 남은 작업

- 첫 프로젝트의 데이터 출처·문제 정의·분석 방법·결과를 검증한 뒤 프로젝트 카드에 추가
- 3주차에 Git 저장과 GitHub Pages 첫 배포
- 공개한 결과물이 생기면 프로젝트 카드에 확인한 링크 추가

## 도구

`index.html`과 `style.css`는 수업에서 제공한 시작 파일을 바탕으로 Claude Code의 도움을 받아 수정했습니다.
페이지에 들어간 내용(이력, 자격증, 관심 분야, 프로젝트 주제와 상태)은 본인이 정한 것이며, 확인은 본인이 직접 했습니다.
